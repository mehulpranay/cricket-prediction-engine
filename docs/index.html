Cricket Prediction Engine

An LLM (DeepSeek) writes a yes/no question and a win probability for each upcoming match before it starts. Markets lock minutes before the start, then resolve from the official result. Every number below comes from the database in this repo.

The database

Everything is in one SQLite file, committed to the repo by the scheduled run: download predictions.db.

Table predictions: matchId, team1, team2, seriesName, match_format, match_start_time, lock_time, market_status (OPEN / LOCKED / RESOLVED / VOID), question, probability, probability_reasoning, resolution_rule, reasoning, actual_outcome, is_correct, brier_score, created_at.

Try: sqlite3 predictions.db "select question, probability, actual_outcome, brier_score from predictions where market_status='RESOLVED'"

Probabilities are the model's raw output (no calibration applied here). Brier score = (probability - outcome)2; always saying 50% scores 0.25. Your guesses are stored in your own browser only.
